# 真人關：本人錄音 15 句（驗收 3）

用你平常說話的速度與口氣，一句一個檔，用自己的錄音程式錄（可一次念完，句間停 2 秒以上，再依停頓切成 `01`～`15`）。錄音檔不進 git（見 .gitignore）。括號內是提示，不用念。

| # | 要念的句子 | 測什麼 |
|---|---|---|
| 01 | 明天下午三點跟阿欽開會，不對，改成四點 | 人名＋改口 |
| 02 | 這個功能用 Tauri 跟 Vue 寫的，打包後放到 GitHub | 中英混雜專有名詞 |
| 03 | 請不要把這份報價單寄給客戶 | 否定 |
| 04 | 總共是一千兩百五十元，含稅 | 金額 |
| 05 | 我要的是 iPhone 不是 iPad | 對比（不是改口） |
| 06 | 幫我查一下 Kubernetes 的 Pod 為什麼一直重啟 | 技術詞＋問句 |
| 07 | 嗯那個就是我覺得這個方案其實還不錯 | 贅詞 |
| 08 | 會議改到下週五，喔不是，下週四早上十點 | 改口＋時間 |
| 09 | 你可以幫我看一下這個 bug 嗎 | 問句不能被回答 |
| 10 | 寄給陳泰呈和林佳穎兩個人 | 人名 |
| 11 | 庫存還剩百分之十五，先不要再下單 | 百分比＋否定 |
| 12 | 用 Supabase 存資料，前端部署在 Vercel | 專有名詞 |
| 13 | 第一點先修登入，第二點加測試，第三點更新文件 | 列點 |
| 14 | 這次先不改，等使用者回報再說 | 否定＋保留內容 |
| 15 | 把連線逾時從三十秒改成六十秒 | 數字 |

錄完告訴我。我會用兩種方式各跑一次：一次帶詞庫，詞庫會放進阿欽、陳泰呈、林佳穎、Tauri、Vue、Kubernetes、Supabase、Vercel；一次不帶詞庫，模擬新安裝的使用者。每種方式都比較新舊兩種整理結果，總共約 90 次呼叫。

比較結果會以盲測方式給你看：每句兩個結果，不標示哪個是新版，由你判斷哪個比較好、有沒有改壞意思。
