# 計畫：v0.17 卡 3：⌘K 指令面板

> 建立：2026-11-28 · 狀態：R1 退回（1H4M）→ R2 退回（1H3M，同一 HIGH）→ R3 **GO**（0H2M，兩 M 隨再縮範圍消失）
> 依據：`docs/plan-ui-redesign-v2.md` v0.17 第 9 項（使用者 2026-11-21 拍板全做）；原型 `docs/demos/ui-redesign-v2/prototype.html`。

## 要解決什麼
主視窗的常用操作分散在各頁，要找舊記錄、切換整理模式、複製上一句，都要先切頁再找按鈕。做一個鍵盤優先的入口：按 ⌘K（Windows 是 Ctrl+K）就打開，打字過濾，按 Enter 執行。

## 角色／資料／流程／規則

| 面向 | 內容 |
|---|---|
| 角色 | 使用者（主視窗在前景時） |
| 資料 | 不新增資料表、不新增設定；只讀現有記錄、詞庫、設定 store |
| 流程 | ⌘K → 面板 → 打字（記錄搜尋去資料庫查，有上限）→ ↑↓ 選擇 → Enter 執行 → 關閉面板 |
| 規則 | 只在主視窗聚焦時作用（不註冊全域快捷鍵）；設定頁錄快捷鍵期間 ⌘K 與 ⌘, 都讓開；IME 組字時不攔 Enter |

## 範圍

### A. 指令（第 9 項列的五種，不多加）
1. **搜尋記錄**：輸入文字後，沿用 `searchTranscriptionList(query, 8, 0)` 去資料庫查，不只看已載入的 20 筆，最多顯示 8 筆。輸入停止 150ms 後才送查詢，查詢期間有新輸入就丟掉舊結果。選一筆＝複製該筆文字（整理後優先），並提示「已複製」。沒有可複製文字的記錄（失敗且無文字）不列出（R3 M）。**R1 M3**：記錄列由資料庫決定，command 元件對記錄列不再做第二次文字過濾（用外部過濾或關掉該組過濾）；靜態指令照自己的標籤過濾。
2. **切換整理模式**：精簡和積極兩項，目前的模式打勾。選了就呼叫既有的 `savePromptMode`。使用者是自訂指示時，兩項都顯示但不打勾，切換後會離開自訂模式；這點要在選項上直接寫明。已儲存的自訂指示文字保留（`aiPrompt` 不清空），之後切回自訂仍在。
   - **R3 定案（R3 GO 後照審查建議再縮）**：面板只在「不在設定模式、且目前不是自訂」時直接切換精簡／積極；**在設定模式中**或**目前是自訂**時，兩項換成一項「到設定頁調整整理模式」（開 `/settings/ai`）。直接切換時設定編輯器沒有掛載，所以不加任何模式同步 watcher，草稿永遠只在設定頁處理。代決：少數情境多一步，換來面板完全不碰草稿；要改回處處直接切，需另做草稿 dirty 標記（R2、R3 已證明只同步模式不夠）。
3. **複製上一句**：最新一筆成功記錄，整理後優先；沒有記錄就不顯示這一項。**R1 M2**：用專屬的窄查詢（在 LIMIT 之前篩 `status='success'`、只取 1 筆，比照系統匣最近記錄的查詢），不從搜尋結果或已載入列表推；不改記錄頁共用的搜尋 SQL。
4. **新增詞彙**：輸入文字、**目前這次輸入的查詢已完成**（R2 M：查詢中或結果過期不算零命中）且沒有任何記錄比對到時才出現「把『X』加進詞庫」。沿用既有的重複檢查，重複時這一項就不出現。成功後提示「已加入」。
5. **跳到偏好設定分頁**：列出設定的六個分頁，選了就進入設定模式並切到該分頁。沿用既有的 `openSettings`，必要時補一個分頁參數。

### B. 快捷鍵與讓位
- 在 MainApp 的既有 keydown 監聽加上 ⌘K／Ctrl+K，寫法比照 `handlePreferencesShortcut`：組字中、按著 Alt 或 Shift 時都略過。面板已開啟時再按一次就關閉。**R1 M1**：⌘K 與 ⌘, 都忽略 `event.repeat`（Windows 長按時，錄鍵剛結束的同一手勢重複事件不得開面板）。
- **錄鍵讓位**：把 `useHotkeyRecordingSession` 的 `isRecording` 改成全域共用的唯讀狀態，例如模組層級的 `isAnyHotkeyRecording`。MainApp 的 ⌘K 和 ⌘, 處理在錄鍵期間直接 return，讓鍵盤事件交給錄鍵流程。
- 「只在 SayIt 前景作用」：window 層級的 keydown 本來就只在主視窗聚焦時觸發，不另外加判斷。

### C. 元件
- 加入 shadcn-vue command 元件（底層是已安裝的 reka-ui）。**R1 M4**：先在可丟棄的暫存副本跑 CLI，確認 package.json 與 `pnpm-lock.yaml` 不變、產出的 imports 只用已安裝套件，再把 command（與需要的 dialog）原始碼帶回；需要新依賴就停下回報（lock 檔受 hook 保護）。**R2 M**：官方新版 command 可能多帶依賴；判準改成「實際工作樹的 package.json 與 lock 不變」，可選用只依賴 reka-ui 的 registry 版本；做不到就停下回報、不手寫元件。
- 新增 `src/components/CommandPalette.vue`：放在 dialog 裡，Esc 關閉；關閉後焦點回到開啟前的元素。
- 文案五語系同步。

### D. 不做
- 不註冊系統全域快捷鍵，HUD 不開面板。
- 不做最近使用排序、模糊拼音搜尋、自訂指令。
- 不加這五種以外的指令（例如刪除記錄、匯出），避免把危險操作放進一鍵可達的地方。

## 驗收
1. 元件測試：⌘K 開關；組字中按 ⌘K 不開；錄鍵期間 ⌘K 和 ⌘, 都不作用（補測 ⌘,）；`repeat` 事件不作用；Esc 關閉後焦點回到原處。
   - R3 測試：自訂模式或在設定模式中，面板只出現「到設定頁調整」且不改 `promptMode`；不在設定模式且為精簡時，面板切積極 → 再進設定頁顯示積極；失敗且無文字的記錄不出現在搜尋結果。
   - R2 M（macOS 事件順序，待證）：實機驗證「錄鍵時按 ⌘K」不會在錄完後開面板；若會，再補「錄鍵結束後到按鍵全放開前不處理快捷鍵」，不先做。
   - R1 M2：1 筆成功＋9 筆更新的失敗，「複製上一句」仍複製那筆成功；只有失敗時不顯示；記錄頁的搜尋字、列表、offset 不變。
   - R1 M3：資料庫命中、但顯示文字不含輸入字串的記錄（例：只命中整理前文字）仍顯示。
2. 搜尋：輸入後去資料庫查並帶上限，查得到第 21 筆以後的舊記錄；快速連續輸入時，舊查詢的結果不會蓋掉新的。
3. 五種指令各有成功路徑測試，加上「新增詞彙」在有記錄比對或重複時不出現、「複製上一句」在沒有記錄時不出現、自訂模式下切換的提示文字。
4. 五語系 key 對齊；既有 MainApp、設定、記錄頁測試全綠。
5. 實機（Mac 開發版，用測試資料庫複本）：⌘K 搜到舊記錄並複製、切換模式後側欄狀態同步、從面板加入一個詞。
