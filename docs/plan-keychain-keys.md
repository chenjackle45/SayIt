# 計畫：前置② 第一步 — Mac 金鑰改存鑰匙圈（本機，不同步）

> 建立：2026-11-28 · 狀態：計劃閘 R1 退回（2 HIGH）＋裁決**拿掉舊式登入鑰匙圈中繼站**：等前置① 驗證完，直接用可同步的資料保護鑰匙圈一次到位（省第二次搬遷與授權驗收；代價：等待期間金鑰仍是明文）→ **本卡依賴前置①**，修訂後重審
> R1 待收進的 HIGH：H1 搬遷刪設定檔後「設定已更新」事件讓另一視窗把四個記憶體欄位寫成空字串；H2 讀回失敗留下舊設定、之後只刪鑰匙圈 → 重啟又搬回（刪除後復活）。另有漏讀點：升級提示、引導資格、評估腳本。依賴：security-framework（Cargo.lock 新增一行）。審查全文：`/private/tmp/codex-review.85sfVo/review.md`
> 範圍：只做「本機鑰匙圈」。iCloud 鑰匙圈同步（第二步）依賴前置① 的 iCloud 權限驗證，另開卡；本卡設計須讓第二步只改「存放屬性」、不再搬第二次資料。

## 要解決什麼
- 四家服務金鑰（Groq／OpenAI／Anthropic／Gemini）目前以**明文**存在設定檔（`tauri-plugin-store`，鍵 `groqApiKey`、`openaiApiKey`、`anthropicApiKey`、`geminiApiKey`），任何能讀使用者資料夾的程式都拿得到。
- 前置② 的最終目標是金鑰經 iCloud 鑰匙圈同步到 iOS；第一步先把金鑰搬進 macOS 鑰匙圈。

## 現況（已查證）
- 讀：設定 store 啟動載入與 `refreshApiKey`／`refreshLlmApiKey` 從設定檔讀四個鍵。
- 寫／刪：`saveApiKey`／`deleteApiKey`（Groq）與對應的 LLM 金鑰函式寫設定檔，並發 `SETTINGS_UPDATED` 事件同步另一個視窗。
- 專案規則：API Key 只能存 `tauri-plugin-store`、不得進 SQLite（本卡把「只存 store」改為「Mac 存鑰匙圈、Windows 仍存 store」，需同步改 CLAUDE.md 禁忌第 4 條的文字）。

## 做法
### 角色與資料
| 角色 | 做什麼 |
|---|---|
| Rust（新） | 三個指令：讀／存／刪，參數只有服務名（groq／openai／anthropic／gemini）。Mac 走鑰匙圈，Windows 回傳「不支援」讓前端沿用設定檔 |
| 前端設定 store | 讀寫金鑰時：Mac 呼叫上面三個指令；Windows 照舊用設定檔。記憶體中的值與事件同步不變 |
| 鑰匙圈項目 | 一般密碼項目；service＝`<App identifier>.apikey`（測試身分 `com.sayit.app.hwtest` 自然隔離）、account＝服務名 |

### 搬遷（只在 Mac、啟動載入時、每個服務各自判斷）
```
鑰匙圈有值 → 用鑰匙圈；若設定檔還留著舊值 → 刪掉設定檔的
鑰匙圈沒值、設定檔有值 → 寫進鑰匙圈 → 讀回比對相同 → 才刪設定檔的
寫入或讀回失敗 → 保留設定檔、照常用設定檔的值、記錄錯誤（下次啟動再試）
兩邊都沒有 → 空
```
- 永遠先寫新、驗證、再刪舊；任何一步失敗都不會讓使用者的金鑰消失。

### 刻意的選擇
- **用「登入鑰匙圈」（舊式檔案型）**，不用需要簽章權限的「資料保護鑰匙圈」：後者要 `keychain-access-groups` 權限＋描述檔，那是前置① 還在驗證的東西。代價：第二步改 iCloud 同步時要再把項目從舊式搬到資料保護鑰匙圈（同一組搬遷規則，service／account 不變）。→ **列給計劃閘裁決**：要不要乾脆等前置① 驗證完，一次搬到可同步的鑰匙圈，避免搬兩次。
- **Windows 不動**：目標只要求 Mac；Windows 不同步，說明裡寫清楚。
- **不新增系統權限**：App 存取自己建立的鑰匙圈項目不需要新權限、正式簽章版不會跳授權視窗。開發版每次重新編譯簽章不同，可能跳「允許存取鑰匙圈」視窗 → 實機驗收用正式簽章測試版確認。

## 不做
- iCloud 同步（第二步）、iOS 讀取、Windows 憑證管理員。
- 金鑰以外的設定搬家。

## 驗收
1. Rust：讀／存／刪以可替換的存放介面實作，單元測試用記憶體替身；服務名白名單外的參數一律拒絕。
2. 前端：搬遷四種情況逐案測試（含「寫入失敗保留設定檔」「讀回不符不刪」）；Windows 路徑行為不變的既有測試不回歸。
3. 隱私：金鑰不出現在任何日誌（斷言日誌參數不含哨兵金鑰）。
4. 實機（測試身分、正式簽章測試版）：舊版設定檔有金鑰 → 升級後鑰匙圈存取程式看得到 SayIt 項目、設定檔裡金鑰已消失、轉錄與 AI 整理照常；刪除金鑰後鑰匙圈項目也消失；不跳授權視窗。
