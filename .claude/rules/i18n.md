# i18n 規則

> 2026-09-11 新建；內容整理自 `docs/development-guide.md` §4.5 與 v0.11.0／v0.12.0 發版實務。

- **五語系同步**：`zh-TW`、`zh-CN`、`en`、`ja`、`ko` 五個 JSON 同時加、同時改；少一個語系 vue-i18n 會在該語系顯示 key 名
- 元件內 `const { t } = useI18n(); t('your.key')`；全域場景（如 prompt 組裝）用 `i18n.global.t('your.key')`
- 改完用 `jq -e . src/i18n/locales/*.json` 驗 JSON 合法
- **純 i18n key 改動不過 codex 閘**（全域準則例外組）；但揭露性文案（例如「記錄檔含轉錄文字」「CSV 不支援引號內逗號」）算功能契約，改動要能追回某條 finding 或需求
- **更新摘要彈窗**：每次發版把 `mainApp.upgradeNotice.item1`～`item5` 換成該版重點（五語系），條數對應 `src/MainApp.vue` 的 `upgradeNoticeItemCount`；步驟見 `docs/development-process.md`「發版」段
- zh-CN 用簡體與「”“」引號，zh-TW 用「」；ja／ko 由 zh-TW 語意翻譯，不從 en 二次翻
